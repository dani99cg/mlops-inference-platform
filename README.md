
# ML Ops Inference Platform

A portfolio project demonstrating how to build, test, package,
deploy and monitor a machine learning inference service.

## Goals

- Serve a machine learning model through a Python API.
- Package the service with Docker.
- Automate testing and validation with CI/CD.
- Deploy the service locally with Kubernetes.
- Track experiments and models with MLflow.
- Monitor service health and performance.

## Technology stack

- Python
- Git and GitHub
- Docker
- GitHub Actions
- Kubernetes
- MLflow
- Prometheus and Grafana
